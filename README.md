# みちみち

行き先を自分で決めずに出かけるためのアプリの体験版。

AIが判断するのは、そこが自分にとって未知かどうかと、行けるかどうかだけ。場所の良し悪しは判断しない。未知の場所へ、ライトで照らしながら向かっていく。到着して初めて町名がわかり、封筒の一語が探す口実になる。

GMO DESIGN AWARD 2026 応募作品（テーマ「トキメキ」／プロダクト部門）

## 体験版について

画面の右（スマートフォンでは下）にある「操作盤」は、**歩く動作を再現するための体験版だけの仕組み**で、実機には存在しない。実機では使用者自身がスマートフォンのコンパスを見ながら歩く。

舞台は京都・一乗寺駅のまわり。地図・町名・地形は実在のデータで、電車の時刻とのりば番号は体験用のシナリオである。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体 |
| `data.json` | 地図・町名・標高・区画のデータ |
| `base_light.jpg` | 地形の陰影画像 |

外部から読み込むのは Google Fonts（Zen Kaku Gothic New／IBM Plex Mono）のみ。

静的ファイルなので、そのまま配信すれば動く。ただし `index.html` を直接開く（`file://`）と、`data.json` の読み込みが CORS で失敗する。サーバ経由で開くこと。
